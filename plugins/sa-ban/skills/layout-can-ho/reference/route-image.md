# 图片路线：户型图 / 截图 / 扫描件

适用：房产平台 / 家装设计平台户型图、售楼处户型图、手绘带尺寸的平面图、只有位图的 PDF（先用 `fitz` 200dpi 渲染成 PNG）。黑底 CAD 截图见文末「黑底 CAD 截图」。

### 1. 读图

查看户型图，记下：
- 最外圈总尺寸（总宽、总深 mm），以及分段尺寸
- 每个房间的名字和位置，门（开向、门轴在哪端）、窗、推拉门、入户门
- 门窗的具体类型：子母门、折叠门、隐形门；平开窗、推拉窗、落地窗、高窗、飘窗（判断方法见格式说明“门窗”一节）
- 承重墙（多数户型图用黑色/深色实心表示），柱、烟道、管井
- 指北针方向（写进 `north`）；用户提到城市就写进 `site`，日照模拟会按当地纬度算
- 图上标的面积，用来事后核对

图没有任何尺寸时，问用户要一个已知尺寸（比如某面墙多长），或者按常见尺寸估算，并且在交付时说明比例是估的。

### 1.5 拉正（rectify.py，有尺寸标注时默认先做）

```bash
python scripts/dimticks.py 户型图.jpg --out <工作目录>/ticks                    # 自动找尺寸线和刻度：ticks.png 上 L0、L1… 编号
#   写 chains.json：每条尺寸线配上图上的数字（格式见 rectify.py 开头），四周的尺寸链都写最准
python scripts/rectify.py 户型图.jpg --chains <工作目录>/chains.json --out <工作目录>/rect
python scripts/rectify.py 户型图.jpg --deskew --out <工作目录>/rect                # 还没读尺寸：只把小角度歪斜转正
```

按尺寸线刻度（像素）+ 标注数字（毫米）拟合透视（单应矩阵），再按每个刻度的残差分段修正（同 axismap），重采样成**每像素固定毫米数**的 `rectified.png`：
- 手机拍照 / 拍屏幕（梯形透视）、扫描件歪斜、户型图本身画得比例不均（同一张图横竖比例差几个百分点）一次去掉。
- 之后 analyze / wallfit / wallaudit / coverage / doorcheck / 底图**全用拉正图**，像素 → 毫米就是 `x + px × mmPerPx`，不用再在生成脚本里套 Axis；底图和模型严格重合，各个对账才不会因为底图没对齐而误报。
- 墙太细（100mm 的隔墙不到 6px）时自动放大 2 倍输出，量墙面更准。
- 打印每个刻度的拟合残差；**偏 60mm 以上的刻度多半是数字读错 / 刻度配错**，先核对再用。`check.png` 上绿圈 = 对得上、红圈 = 残差大。
- 生成脚本里要把原图像素换算成毫米：`from rectify import Rectified; R = Rectified('rect/rectify.json'); X, Y = R.mm(px, py)`。
- 实测：户型图5（拍屏幕的照片，有透视）42 个刻度，整体透视拟合残差 rms 15mm，分段修正后刻度全部落在标注位置。

### 2. 自动识别墙体（初稿 + 比例）

```bash
python scripts/analyze.py 户型图.jpg --total-width 12340 --total-height 11940 --out <工作目录>/analysis
```

- 输出 `mmPerPx`（比例），`scale_check` 里是按宽、按深分别算的比例。两者差 2% 以内说明比例可信。
  差得多通常是因为有凸出部分（飘窗、阳台）超出了总尺寸的范围：改用 `--dim 像素x0 像素x1 毫米`，按某一段标注线两端的像素位置定比例。
- `analysis.png`：原图 + 识别出的墙段（W 编号，红色 = 承重墙，橙色 = 非承重）+ 断口（G 编号，门窗候选）+ 尺寸线刻度（T/B/L/R 编号的紫色圈）+ 像素标尺，用来读坐标。
- **承重墙**：脚本按墙芯颜色自动分两类（深色 = 承重，`bearing_by: "color"`）。图上所有墙同一个颜色时只能按厚度猜（`bearing_by: "thickness"`），
  这些墙在 analysis.png 上编号带 `?`、也列在输出的 `bearing_unsure` 里——**必须对照原图图例逐面确认**（图例常写“承重墙 / 非承重墙 / 新建墙”）。
  常见画法：承重墙黑色或深灰实心、斜线填充；非承重墙浅灰实心或只画两条边线；外墙一般按承重处理；厨卫的 100~120mm 薄墙基本是非承重。
  颜色分界不对时用 `--bearing-max 亮度` 手动指定（承重墙颜色的最大亮度，0~255）。
- 拉正过的图：`python scripts/analyze.py rect/rectified.png --scale <mpp> --origin <x> <y>`（rectify 打印的），draft.json 直接是 spec 坐标。
- 隔墙只画了两条细边线、中间是白的（房产平台户型图常见）：**自动判断**（实心墙凑不够一圈外墙就按描边画法识别），也可以手动 `--outlined`。
- 彩色户型图里亮度 175~215 的浅灰隔墙自动补上（只收细长、贴着已识别墙体的块；`--no-light-walls` 关闭）。
- 墙在窗处断开、窗另一头接的是转角：墙端往前看到最近的垂直墙，中间墙带里有 ≥ 2 条贯通的窗线 / 彩色窗块就把墙延过去并记一个窗。
- 墙体按距离聚簇取总面积最大的一簇当房子（客餐厅没有深色墙的大平层以前会丢掉大半个户型）。
- 黑底 CAD 截图给了 `--scale` 没给 `--wall-color` 时，各种线色都试一遍、双线墙带面积最大的颜色当墙线（白墙线 + 绿尺寸线的也认得出）。
- `analysis.json` 的 `dims_px`：每条尺寸线上的刻度（尺寸界线）像素位置，下一步精确定位墙要用。
- `draft.json`：直接可用的 HouseSpec 初稿（墙 + 门窗候选 + 底图参数）。**识别会漏墙**，漏掉的通常是：被窗户打断的墙段、很细的隔墙、浅色玻璃隔断；门窗类型也只是猜测。
- 墙体颜色偏浅、识别不到时调 `--gray-max 200`。图例、logo 被误识别成墙时用 `--crop x0 y0 x1 y1` 限定范围。
